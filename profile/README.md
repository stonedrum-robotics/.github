# Stonedrum Robotics

Stonedrum is a robotics company in Europe working across hardware, data and integration. This GitHub organization shares hand-interface reference code, in-memory examples and technical reference material for robotics development.

## Explore the repositories

| Repository | What you will find |
|---|---|
| [Dexterous Hand SDK](https://github.com/stonedrum-robotics/dexterous-hand-sdk) | Python hand interfaces and in-memory mock examples. Vendor adapters are incomplete. |
| [Demo apps](https://github.com/stonedrum-robotics/demo-apps) | One mock grasp script and four integration scaffolds, with per-example status. |
| [Hardware resources](https://github.com/stonedrum-robotics/hardware-resources) | Preliminary integration notes, an accessory list and placeholder directories. |
| [Documentation](https://stonedrum-robotics.github.io/docs/) | Legacy documentation; use repository READMEs for the current scope of the code. |

Start with the SDK's mock example to inspect joint-state inputs and outputs. These mock examples use in-memory joint values; they do not simulate physical contact or establish hardware compatibility.
